# Word swaps

Common swaps for the writing rules. Use the right column. The list is a guide,
not a dictionary: if a word on the left is the clearest choice in context, keep
it.

## Phrasal verbs

| Instead of   | Write                      |
| ------------ | -------------------------- |
| set up       | configure, create, install |
| figure out   | find, calculate            |
| find out     | learn, find                |
| look into    | examine, investigate       |
| carry out    | do, perform                |
| come up with | write, design              |
| get rid of   | remove, delete             |
| go through   | read, examine              |
| kick off     | start                      |
| kick over to | redirect to, send to       |
| pick up      | read, receive, detect      |
| point out    | show, say                  |
| run into     | meet, cause (an error)     |
| show up      | appear                     |
| shut down    | stop                       |
| spin up      | start, create              |
| turn on, off | enable, disable            |
| wire up      | connect                    |
| hand off     | give, send                 |
| fall back to | use (X) if (Y) fails       |

## Sales words

Delete these, or replace them with the fact or measurement that earns them:
seamless, robust, powerful, cutting-edge, effortless, blazing-fast, elegant,
world-class, best-in-class, simply, just, easily.

The replacements below use facts that you must already have. Do not invent a
number to replace a sales word.

| Instead of              | Write                                |
| ----------------------- | ------------------------------------ |
| a robust retry strategy | a retry strategy with three attempts |
| blazing-fast lookups    | lookups in under 5 ms at p99         |
| simply run the command  | run the command                      |

## Stacked hedges

Keep one hedge, with the strength that the evidence supports. Do not delete a
hedge that carries real doubt.

| Instead of                              | Write          |
| --------------------------------------- | -------------- |
| it may potentially help to improve      | it may improve |
| it could possibly be the case that X    | X may be true  |
| it is important to note that this might | this might     |
| this seems to likely suggest            | this suggests  |

## Passive to active

Use these only when you know the actor. If the source does not say who does the
action, keep the passive.

| Instead of                    | Write                            |
| ----------------------------- | -------------------------------- |
| The cookie is set by the API. | The API sets the cookie.         |
| An error is thrown if...      | The parser throws an error if... |
| It is recommended that you... | Do X. / We recommend X.          |
| The tests should be run.      | Run the tests.                   |
